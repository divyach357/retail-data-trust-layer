# Getting the data
1. Accept the rules at https://www.kaggle.com/competitions/m5-forecasting-accuracy (Rules tab).
2. Download the data (Data tab, **Download All**) and unzip it.
3. Copy `calendar.csv`, `sell_prices.csv` and `sales_train_evaluation.csv` into `../data/` (excluded from git).
4. Load them into Snowflake with `../sql/01_setup_and_load.sql`.
